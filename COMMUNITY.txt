Slot Master
Version: 1.0

EN
Slot Master is a Figma utility for bulk synchronization, renaming, card creation,
normalization, title fitting, sorting, and styling of slot-game cards.
by Alexey Kylik.

Create from table:
Select one reference card and generate one physical card per spreadsheet row while
preserving the reference content. Each generated frame uses the row Identifier and
its linked Title.

Shared visual reference:
Create, Normalize, and Title Fit use one visual reference. The selected Figma card
is shown as a preview inside Slot Master.

RU
Slot Master — плагин Figma для массовой синхронизации, переименования, создания,
нормализации, настройки заголовков, сортировки и стилизации карточек слотов.
Автор: Alexey Kylik.

Создание из таблицы:
Выберите одну референсную карточку, чтобы создать отдельную карточку для каждой
строки таблицы с сохранением структуры и содержимого референса.

Общий визуальный референс:
Create, Normalize и Title Fit используют одну референсную карточку, которая
отображается в интерфейсе Slot Master.
